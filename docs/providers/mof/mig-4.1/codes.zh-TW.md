# MIG 4.1：共通型別與代碼

[English](codes.md) | 繁體中文

> 本文譯自英文版。兩者不一致時，以英文版為準。

所有 MIG 訊息共用的型別與代碼表（MIG 第肆章）。來源和標記見 [README.zh-TW.md](README.zh-TW.md)。

## 賣方與買方 (`RoleDescriptionType`)

`[mig 表 4-2]`。「M」表示必填，「O」表示選填。

| 欄位 | M/O | 規則 |
| --- | --- | --- |
| `Identifier` | M | BAN。買方是消費者時，填十個 `0` |
| `Name` | M | 1 到 60 字元。見下方 |
| `Address` | O | 最多 100。F0401 和 G0401 的賣方必填 |
| `PersonInCharge` | O | 最多 30 |
| `TelephoneNumber` | O | 最多 26 |
| `FacsimileNumber` | O | 最多 26 |
| `EmailAddress` | O | 最多 400 |
| `CustomerNumber` | O | 最多 20 |
| `RoleRemark` | O | 40 |

買方的 `Name`：

- 營業人買方：公司名稱。如果依法可以不填名稱，填買方的統一編號。
- 消費者：個人識別碼，讓消費者可以在財政部平台查詢這張發票。不可以是 `0`、`00`、`000` 或 `0000`。從下面擇一：
  1. 消費者的姓名。
  2. 發票有列印，或存在非會員載具時：和隨機碼相同的值。
  3. 發票存在會員載具時：賣方自訂的值，例如載具的末四碼，或會員 email 的前四個字元。

## 發票號碼 (`InvoiceNumberType`)

10 字元，`[A-Z]{2}\d{8}`。例如 `QQ12345678` `[mig 表 4-10]`。

## 日期與時間 (`DateType`, `TimeType`)

日期是西元 `yyyyMMdd`，例如 `20240101`。時間是 `xsd:time`。兩者都是 UTC+8。平台會忽略資料中的任何時區 `[mig 表 4-15, 4-16]`。

## 發票類別 (`InvoiceTypeEnum`)

| 代碼 | 意思 |
| --- | --- |
| `07` | 一般稅額計算 |
| `08` | 特種稅額計算 |

## 折讓證明單號碼 (`AllowanceNumberType`)

1 到 16 字元，由賣方系統編號。平台會拒絕已經用過的號碼，以前年度用過的也一樣 `[mig 表 4-5]`。

## 折讓種類 (`AllowanceTypeEnum`)

| 代碼 | 意思 |
| --- | --- |
| `1` | 買方開立（或作廢）折讓證明單 |
| `2` | 賣方開立（或作廢）折讓證明通知單 |

V4.1 起，所有折讓一律由賣方開立和作廢，所以新的折讓用 `2` `[mig 表 4-6]`。

## 載具類別 (`CarrierTypeEnum`)

6 字元 `[mig 表 4-13, 15-3]`：

| 代碼 | 意思 |
| --- | --- |
| `3J0002` | 手機條碼 |
| `CQ0001` | 自然人憑證條碼 |
| `5G0001` | 跨境電商電子郵件載具 |
| 其他 | 財政部平台核發給賣方或加值中心的代碼。第 1 碼是行業別，第 2 碼是載具種類，第 3 到 6 碼是流水號 |

## 課稅別與稅率 (`TaxTypeEnum`, `TaxRateEnum`)

課稅別 `[mig 表 4-12]`：

| 代碼 | 意思 |
| --- | --- |
| `1` | 應稅 |
| `2` | 零稅率 |
| `3` | 免稅 |
| `4` | 應稅（特種稅率） |
| `9` | 混合應稅與免稅或零稅率。只用在 F0401 表頭 |

稅率 `[mig 表 4-18]`：`0`、`0.01`、`0.02`、`0.05`、`0.15`、`0.25` 之一。5% 寫成 `0.05`。

## 零稅率原因 (`ZeroTaxRateReasonEnum`)

`71` 到 `79`，分別對應營業稅法第 7 條的各款 `[mig 表 4-19]`。`71` 是外銷貨物。課稅別為零稅率時必填。

## 通關方式 (`CustomsClearanceMarkEnum`)

| 代碼 | 意思 |
| --- | --- |
| `1` | 非經海關出口 |
| `2` | 經海關出口 |

零稅率發票必填 `[mig 表 4-9]`。

## 保稅區 (`BondedAreaEnum`)

買方用來註記零稅率銷售的對象：保稅區、遠洋漁業或自由貿易港區。`1` 到 `4`，`4` 是「其他」`[mig 表 4-17]`。

## 買方註記 (`BuyerRemarkEnum`)

`1` 得抵扣之進貨及費用、`2` 得抵扣之固定資產、`3` 不得抵扣之進貨及費用、`4` 不得抵扣之固定資產 `[mig 表 4-8]`。

## BAN

8 到 10 位，只能是數字（V4.1 起）。營業人買方或賣方填統一編號。消費者買方填 `0000000000` `[mig 表 4-7]`。

## 捐贈 (`DonateMarkEnum`)

`0` 不捐贈，`1` 捐贈 `[mig 表 4-11]`。賣方必須接受買方在交易當下提供的捐贈碼。境外電商（營業稅法第 6 條第 4 款）是例外。

## 發票期別 (`YearMonth`)

5 位數字：民國年加上兩個月期別的結束月份（偶數月）。`11102` 是民國 111 年（2022）1、2 月。月份一定是 `02`、`04`、`06`、`08`、`10` 或 `12` `[mig 表 20-3]`。

## 發票狀態 (`CurrentStatus`)

發票在財政部平台上的狀態，由 E0502 回報 `[mig 表 23-2]`：

| 代碼 | 意思 |
| --- | --- |
| `1` | 開立未確認 |
| `2` | 開立已確認 |
| `3` | 作廢未確認 |
| `4` | 作廢已確認 |
| `5` | 退回未確認 |
| `6` | 退回已確認 |
| `7` | 已註銷 |

「確認」指 B2B 交換流程中，對方送出的確認訊息（見 [exchange.zh-TW.md](exchange.zh-TW.md)）。

## 折讓狀態 (`CurrentStatus`)

折讓在財政部平台上的狀態，由 E0503 回報 `[mig 表 24-3]`：

| 代碼 | 意思 |
| --- | --- |
| `1` | 折讓未確認 |
| `2` | 折讓已確認 |
| `3` | 作廢未確認 |
| `4` | 作廢已確認 |
| `7` | 已註銷 |
